4. DEPLOYMENT OPTIONS & STEP-BY-STEP GUIDE
--------------------------------------------------------------------------------

OPTION A: VERCEL DEPLOYMENT (RECOMMENDED FOR NEXT.JS PWA)
--------------------------------------------------------
1. Push code to GitHub repository:
   git add .
   git commit -m "Deploy: BiteBuddy 2.0 First 50 Customers Production MVP"
   git push origin main

2. Import Repository into Vercel:
   • Go to https://vercel.com/new
   • Select the repository
   • Framework Preset: Next.js
   • Root Directory: ./

3. Configure Environment Variables:
   • Add all environment variables listed in Section 3 above.

4. Deploy:
   • Click "Deploy". Vercel will build all 47 routes in ~25 seconds.
   • The included `vercel.json` file will automatically configure the 4 crons!

OPTION B: SELF-HOSTED DOCKER / RAILWAY / DIGITALOCEAN / VPS
-----------------------------------------------------------
1. Build the production application:
   npm run build

2. Start the production server:
   npm run start
   (Runs on http://localhost:3000 by default, behind Nginx with SSL)

3. Setup External Cron Trigger (e.g. Cron-Job.org / crontab):
   • 10:00 AM (Mon-Fri) : curl -H "Authorization: Bearer <CRON_SECRET>" https://your-domain.com/api/cron/daily-reminder
   • 06:30 PM (Mon-Fri) : curl -H "Authorization: Bearer <CRON_SECRET>" https://your-domain.com/api/cron/cutoff-warning
   • 07:01 PM (Mon-Fri) : curl -H "Authorization: Bearer <CRON_SECRET>" https://your-domain.com/api/cron/auto-default
   • 05:00 PM (Friday)  : curl -H "Authorization: Bearer <CRON_SECRET>" https://your-domain.com/api/cron/weekly-summary

5. DATABASE INITIALIZATION (IF USING SUPABASE / POSTGRESQL)
--------------------------------------------------------------------------------
If deploying with Supabase or standard PostgreSQL:
1. Open Supabase Dashboard -> SQL Editor.
2. Paste the contents of `schema.sql` (located at the root of this project).
3. Click "Run". All tables, foreign keys, unique constraints, and indexes will 
   be created automatically.
4. If migrating legacy data from SQLite:
   python scripts/migrate-sqlite.py -> generates migration.sql -> execute in SQL Editor.
